# ตำปูม้าคาเฟ่

เว็บไซต์หน้าเดียวสำหรับร้านตำปูม้าคาเฟ่ — Food, Coffee, River & Music

## เนื้อหา

- เรื่องราวและจุดเด่นของร้าน
- เมนูแนะนำพร้อมตัวกรอง
- แกลเลอรีบรรยากาศและไลต์บ็อกซ์
- ตารางดนตรีสด รีวิว และข้อมูลติดต่อ
- ปุ่มโทร แผนที่ และ Facebook
- รองรับมือถือ คีย์บอร์ด และการลดการเคลื่อนไหว

ข้อมูลร้านที่แก้ไขบ่อยอยู่ใน `data/store.ts` ส่วนรูปที่ยังไม่ได้รับจากเจ้าของร้านจะแสดงเป็นช่องภาพกำกับไว้อย่างชัดเจน

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

ตรวจสอบเวอร์ชันสำหรับเผยแพร่ด้วย:

```bash
npm test
```
